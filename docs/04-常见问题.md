# 常见问题

> 先按 Ctrl+F 搜关键词。这里没有的，看 [03-识别规则与已知限制.md](03-识别规则与已知限制.md) 或对应端的使用说明。

---

## 一、安装与启动

**Q：Windows 提示「已保护你的电脑」，还能用吗？**
能用。程序没有购买数字签名证书，点「更多信息 → 仍要运行」即可，不影响功能。

**Q：双击 exe 之后什么都没发生？**
界面是在浏览器里打开的，不是弹一个窗口。看任务栏浏览器的标签页，地址应该是 `127.0.0.1:某端口`。如果浏览器没起来，检查默认浏览器设置，或手动把 `127.0.0.1:端口` 粘进浏览器。

**Q：第一次启动要等 1–2 秒？**
正常。单文件程序要先自解压到临时目录。

**Q：安卓装不上 / 提示「应用未安装」？**
只支持 arm64-v8a 机型（近几年的手机基本都是）。如果是旧 32 位机型，装不上属正常。

**Q：安卓提示「未知来源应用」？**
系统对非应用商店安装的包都会提示，允许当前文件管理器/浏览器安装即可。

## 二、识别不准

**Q：扫描件一个字都没识别出来？**
扫描件是整页图片、没有文字层，自动识别无从下手。这是设计上的限制，不是 bug——界面左上角有红字提示。请用**手动框选**，打码效果一样不可还原。

**Q：某个姓名 / 号码漏了？**
先看 [03-识别规则与已知限制.md](03-识别规则与已知限制.md) 第 5 节的已知限制（换行拆开、以「镇路村」结尾、中文数字等）。属于限制的，手动框选补上。

**Q：把不该打的内容打了？**
- 在列表里取消那一处的勾选；或
- **双击页面上那个方框**，立刻取消（本版新增，两端都支持）。

**Q：为什么「疑似」条目默认不打勾？**
"看着像人名但证据不够"的候选，默认放过，避免误打正文里的普通名词。确认是人名就手动勾上。

**Q：为什么姓名只遮名字、留着姓？**
这是刻意的：很多场景（名单、通讯录）需要能分辨是哪一位，全遮反而没法核对。规则是 `陈嘉豪 → 陈██`。

## 三、保存与文件

**Q：打码后的文件存到哪了？**
按这个顺序：① 你在弹窗里指定的目录；② 设置里的默认保存位置；③ 什么都没设时，Windows 拖入的文件进「下载」文件夹、双击打开的进原文件旁边；安卓按你授权过的目录。生成完成的界面里都有「打开所在文件夹」。

**Q：原文件会被改吗？**
不会。原 PDF 始终只读，输出永远是新文件，重名自动加序号，不覆盖。

**Q：安卓每次都要弹窗选目录，很烦？**
设置 → 保存位置，授权一个目录并勾「不再询问」，之后静默写入。Windows 同理，勾「不再询问」。

**Q：打码后还能复制出原文吗？**
不能。打码同时把该区域的文本层删掉了，复制、搜索、提取文字都拿不到。

**Q：能"反马赛克"还原吗？**
不能。像素与原文已无对应关系。

## 四、检查更新相关

**Q：点「检查更新」提示失败？**
按这个顺序查：

1. 安全软件 / 家长控制有没有拦截浏览器；
2. 系统「设置 → 网络和 Internet → 代理」是不是开着；
3. 防火墙有没有拦本程序联网。

都排不掉就点「复制链接」把链接粘到浏览器，或者截屏这一屏，用微信「提取文字」把链接抠出来手动输。

**Q：为什么提示「已是最新」但我看到有新版？**
检查更新读的是**安装包文件名里的版本号**（`PDFPrivacyMasker-<版本号>.exe`），读不到才退回 release tag。如果发布的附件没按这个格式命名，就会判断失败。命名规则见 [05-构建与发布.md](05-构建与发布.md) →「发布 Release」。

**Q：一打开就弹「正在检查更新」，能关掉吗？**
能。那个窗口右上角有 ×，安卓端底部还有「跳过，先进入」。它只在你网络较慢（超过 1.2 秒还没结果）时才出现——网络正常时几毫秒就查完了，你根本看不到它。

**Q：断网的时候会不会卡住、或者弹一堆报错？**
不会。自动检查断网、超时、被拦截时都是**静默跳过**：不弹窗、不报错、不重试，直接进主程序，所有本地功能照常。整套超时是 10 秒单次 + 20 秒总预算，够用且不会无限等。

**Q：为什么点「暂不更新」它又多问了一句？**
说明作者在发布说明里标了「更新级别：强烈建议」——通常是这一版修了会天天碰到的问题，所以关之前多劝一次。挽留只有一次：再点「我还是要用旧版（先这样，下次再说）」就真的关掉，直接进主程序。
**任何版本都不会把窗口锁死**，右上角的 × 一直都在；判断级别用的是发布正文那一行标记，没有写标记时一律按普通建议处理。

**Q：更新下载下来的文件名后面多了个 `.zip`，装不上？**
文件本身没坏——Gitee 的附件 CDN 把 `.apk` 标成了 `application/zip`，浏览器按类型给它补了个后缀。把结尾的 `.zip` 去掉就能正常安装。**v1.4.5 起安卓端改成应用内下载**（自己存成 `.apk`、核对包名和版本号再交给系统安装器），不会再出现；从 v1.4.3 / v1.4.4 升上来时还会碰到最后一次。

**Q：按返回键、或者从屏幕边上一滑，应用直接退出了？**
那是 v1.4.5 之前的毛病，已经修好。工作区里还开着文件时，返回会先弹一个小窗口：**继续编辑** / **保存后离开**（已经打出结果时才出现）/ **直接离开**。直接离开是回主页、不是关应用，随时能重新选文件；在主页再按返回才是退出。

**Q：会偷偷联网吗？**
不会。联网只做一件事：检查更新（读一个公开的版本号）。你点了更新之后，安卓端会自己把安装包下下来再交给系统安装器——这也是它需要 `INTERNET` 之外的第二个权限「安装应用」的唯一原因。除此之外不传文件、不传个人信息。

**Q：不想让它自动检查，能关掉吗？**
目前没有开关——因为它足够安静：已是最新时不显示任何东西，断网时也不显示。如果你想彻底断网运行，直接在系统里禁用本程序的联网权限即可，程序会当作「连不上」静默跳过，其它功能不受影响。

## 五、界面相关

**Q：顶部那条「拖动框选 · 双击方框取消/恢复打码」不见了？**
Windows 窗口宽度小于 1040px 时会自动隐藏，避免挤坏工具栏。把窗口拉宽就回来，鼠标悬停原位置也有说明。

**Q：安卓拖框时放大镜太大 / 太小？**
改 `android/app/src/main/java/com/neurotracee/pdfmask/ui/WorkScreen.kt` 里 `LoupeOverlay` 的 `d`（直径，默认 96dp）与 `zoom`（倍数，默认 2.8）。

**Q：安卓看预览时勾选项找不到了？**
点底部那条折叠条，「自动识别结果」面板会从下方升起；收起时勾选状态不会丢（本版修的）。

**Q：切换到英文后还有中文？**
本版已把正文段落、分类标题、默认文件名、掩码格式、状态栏全部纳入词表。仍有遗漏请提 issue，注明具体位置。

**Q：设置面板底部按钮点不到？**
本版已改为屏高 88% 且内容可滚动。如果仍被系统导航栏遮挡，确认不是第三方全面屏手势工具导致的。

## 六、许可与二次开发

**Q：可以商用 / fork 吗？**
可以，不用付钱、不用问作者。但必须保留作者署名、在程序里标注原项目地址、改动过的版本注明"非原作者发布"，并按 AGPL-3.0 公开源码。详见 [ADDITIONAL-TERMS.md](../ADDITIONAL-TERMS.md)。

**Q：作者会及时回复吗？**
维护频率很低，大约一两个月看一次，不要指望秒回。代码全部公开，欢迎自行修改。

**Q：想要闭源商用？**
需要**同时**取得本项目作者的豁免和 PyMuPDF 版权方 Artifex 的商业许可，两条缺一不可。见 [NOTICE.md](../NOTICE.md)。
