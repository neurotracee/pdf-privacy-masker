PDF 隐私打码工具 · 使用说明  v1.4.7.0（Windows）
================================================

完整说明、版本更新记录、常见问题都在开源仓库：
https://github.com/neurotracee/pdf-privacy-masker
本文件只讲最常用的部分。


【一、开始用】
1. 双击 PDFPrivacyMasker-1.4.7.0.exe。
2. 界面会自己在浏览器里打开（地址 127.0.0.1 的随机端口，只有本机能访问）。
3. 把 PDF 拖进虚线框，或点「选择 PDF 文件」。
4. 等 1-2 秒，识别结果逐条列在左边，右边是页面预览（扫描件慢一些，每页约 1 秒）。
   首次启动慢 1-2 秒属正常；若 Windows 提示「已保护你的电脑」，
   点「更多信息 → 仍要运行」即可（程序没有购买数字签名，不影响功能）。


【二、确认与补框】
· 每条结果前面有勾选框，点一下取消 / 恢复；点某一条会跳到对应页并高亮。
· 橙色「疑似」条目默认不打勾，确认是人名再勾上。
· 漏掉的：点上方「框选手动打码」，在页面上按住鼠标拖一个框，松手即成。
· 想取消某一处：在页面上【双击那个方框】，该处打码取消、框变灰；
  再双击一次恢复。自动识别的红框和手画的蓝虚线框都能双击。
  处理页顶部有一条提示：「拖动框选 · 双击方框取消/恢复打码」。


【小提示：关窗口前会问一句】
工作区里还开着 PDF 时，直接关掉浏览器标签页或刷新，浏览器会先弹
「确定要离开吗」——点取消就能留下来。Windows 版没有独立的窗口，
只能用浏览器这个提示，没法自定义文案；安卓版是一问三选：
继续编辑 / 保存后离开 / 直接离开。

【三、生成与保存位置】
点右下角「生成打码 PDF」，先问你要存到哪个文件夹：
· 点「浏览…」选目录 → 「确定」。
· 两个勾选：□ 下次默认使用这个路径   □ 不再询问
· 想改回来：右上角「设置」→ 默认保存位置，用勾选方式改，不用记命令。
· 文件夹不存在会自动创建；原 PDF 只读不改；同名自动加序号，不覆盖。
· 忘了存哪：生成完成窗口里有「打开所在文件夹」。


【四、检查更新】
右上角「设置」→「版本与更新」→「检查更新」。
· 有新版本：直接用默认浏览器打开下载页，同时显示链接和「复制链接」。
· 打不开浏览器 / 网络被拦：按顺序查三项——
    1) 安全软件 / 家长控制有没有拦浏览器；
    2) 系统「设置 → 网络和 Internet → 代理」是不是开着；
    3) 防火墙有没有拦本程序联网。
  还不行就「复制链接」手动粘，或截屏这一屏用微信「提取文字」抠链接。
· 默认每次启动会静默查一次（断网就跳过，不弹窗）；想改成只在点按钮时联网，
  到「设置 → 版本与更新 → 检查方式」选「手动检查」。只读一个版本号，不传文件、不传个人信息。


【五、界面语言】
同一个「设置」面板里可切中文 / English，立即生效不用重启，选择会记住。


【六、它会自动识别什么】
手机号、身份证号、银行卡号、邮箱、姓名、座机号、地址、出生日期、性别、年龄。
· 扫描件 / 拍照件 / 整页图片的 PDF 也会自动识别：没有文字层的页面先用本机
  OCR 认一遍，再套用同一套规则；首次会慢一些，每页约 1 秒。
· 姓名只遮名、留姓：陈嘉豪 → 陈██
· 普通日期、金额、车牌、快递单号、工号等不会被误打。
· 打码是像素重采样 + 抹除文字层，不可还原，也不能"反马赛克"。


【七、已知限制】
· 扫描件 / 拍照件会自动用本机 OCR 识别（离线、不上传）；认不准的地方请手动框选，效果一样不可还原。
· 加密 PDF 需先解除密码。
· 姓名以「镇 / 苑 / 道 / 路 / 街 / 村 / 庄」结尾的会保守放过，请手动框选。
· 被换行拆成两半的姓名、号码可能漏。
· 纯中文数字写的号码不识别。
